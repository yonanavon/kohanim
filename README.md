# משחק תרגול ברכת כהנים

משחק אינטראקטיבי לתרגול **הטיות הראש של שליח הציבור** בעת אמירת ברכת כהנים —
לכל אחת מ-13 המילים בברכה יש תנועה (זקיפה / הרכנה) וכיוון (ימין / אמצע / שמאל).

## מצבי משחק

- **🎓 מצב למידה** — דפדוף בין המילים עם כפתורי החיצים או עם חיצי המקלדת
  (חץ שמאלה = המילה הבאה, חץ ימינה = המילה הקודמת), כשהתנועה והכיוון הנכונים מסומנים.
- **📝 מצב מבחן** — בוחרים תנועה וכיוון לכל מילה ומקבלים משוב מיידי. בסיום מוצג
  הציון, סיכום הטעויות, ואפשרות **לתרגל רק את המילים שבהן טעית**.

הציון הגבוה ביותר נשמר מקומית בדפדפן (`localStorage`).

## הפעלה

הפרויקט הוא קובץ HTML יחיד ללא שלב בנייה. אפשר פשוט לפתוח את `index.html`
בדפדפן, או להגיש אותו משרת סטטי כלשהו:

```bash
python3 -m http.server 8000
# ואז http://localhost:8000
```

נדרשת גישה לאינטרנט כדי לטעון את React, Babel ו-Tailwind מה-CDN.

## מבנה

`index.html` מכיל את הכל: React 18 ו-Tailwind נטענים מ-CDN, וה-JSX מתקמפל
בדפדפן באמצעות Babel Standalone. הקומפוננטה הראשית היא `BlessingGame`,
ורשימת המילים והתנועות נמצאת בקבוע `BLESSING_STEPS`.

> הערה: קימפול JSX בדפדפן נוח לפרויקט קטן אבל איטי יחסית. אם הפרויקט יגדל,
> כדאי לעבור לשלב בנייה (Vite) ולטיילווינד מקומפל מראש.
