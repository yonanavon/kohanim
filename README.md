# ברכת כהנים · תרגול הטיות הראש

משחק אינטראקטיבי לתרגול **הטיות הראש של שליח הציבור** בעת אמירת ברכת כהנים —
לכל אחת מ-13 המילים בברכה יש תנועה (זקיפה / הרכנה) וכיוון (ימין / אמצע / שמאל).

## מצבי משחק

- **מצב למידה** — דפדוף בין המילים עם כפתורי החיצים או עם חיצי המקלדת
  (חץ שמאלה = המילה הבאה, חץ ימינה = המילה הקודמת), כשהתנועה והכיוון הנכונים מסומנים.
- **מצב מבחן** — בוחרים תנועה וכיוון לכל מילה ומקבלים משוב מיידי. בסיום מוצגים
  אחוז ההצלחה, סיכום הטעויות, ואפשרות **לתרגל רק את המילים שבהן טעית**.

הציון הגבוה ביותר נשמר מקומית בדפדפן (`localStorage`).

## עיצוב

העיצוב הוא מערכת ייעודית — כחול לילה עמוק, זהב חם וזכוכית — ללא תלות בפריימוורק CSS.
כל ה-CSS כתוב בקובץ עצמו ומבוסס על משתני CSS (`:root`), כך שאפשר להחליף את כל
לוח הצבעים ממקום אחד.

- טיפוגרפיה: **Frank Ruhl Libre** (סריף עברי) לכותרות ולמילות הברכה,
  **Heebo** לטקסט הממשק.
- דמות הש"ץ מצוירת ב-SVG וקבוצת הראש מסתובבת סביב ציר הצוואר, כך שההטיה
  והכיוון נקראים במבט אחד. מתחתיה מחוון שלוש נקודות לכיוון הנוכחי.
- הכל מותאם RTL, עובד במסכי מובייל, ומכבד `prefers-reduced-motion`.

## הפעלה

הפרויקט הוא קובץ HTML יחיד ללא שלב בנייה. אפשר לפתוח את `index.html`
בדפדפן, או להגיש אותו משרת סטטי כלשהו:

```bash
python3 -m http.server 8000
# ואז http://localhost:8000
```

נדרשת גישה לאינטרנט כדי לטעון את React, Babel והגופנים.

## מבנה

`index.html` מכיל את הכל. React 18 והגופנים נטענים מ-CDN, וה-JSX מתקמפל
בדפדפן באמצעות Babel Standalone. הרכיבים המרכזיים:

| רכיב | תפקיד |
| --- | --- |
| `BlessingGame` | ניהול מצב המשחק וכל שלושת המסכים |
| `Cantor` | דמות הש"ץ ב-SVG, מקבלת תנועה וכיוון |
| `ScoreRing` | טבעת אחוז ההצלחה במסך הסיום |

רשימת המילים והתנועות נמצאת בקבוע `BLESSING_STEPS`.

> הערה: קימפול JSX בדפדפן נוח לפרויקט קטן אבל מוסיף זמן טעינה.
> אם הפרויקט יגדל, כדאי לעבור לשלב בנייה (Vite).
